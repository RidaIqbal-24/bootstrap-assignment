# Bootstrap Assignment - Nexus Code Academy👩🏻‍💻

A fully responsive Code Academy website recreated using HTML, Bootstrap 5, and minimal custom CSS, as per the Web Development Advance Midterm Assignment requirements.

## 🚀 Technologies Used
- **HTML5**
- **Bootstrap 5.3.3** (via CDN)
- **Custom CSS** (used only for specific backgrounds and minor hover effects)

## ✨ Features Implemented
- **Header & Navigation:** Logo on left, nav links on right using Bootstrap Flexbox.
- **Hero Section:** Dark blue background with centered white text, rounded corners, and a "Explore Courses" button (Bonus Task).
- **Courses Section:** 6 course cards (Web Dev, Graphic Design, Digital Marketing, AI, Cybersecurity, Freelancing).
  - *Responsive Grid:* 3 cards per row on Desktop (`col-lg-4`), 2 on Tablet (`col-md-6`), 1 on Mobile (`col-12`).
- **About Us Section:** Two side-by-side boxes (Who We Are & Why Choose Us) using Bootstrap Grid.
- **Contact Section:** Centered text with a light purple background as required.
- **Footer:** Student info and copyright.
